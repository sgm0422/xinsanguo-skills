# xin-sanguo-meme-mode

给 Codex 用的《新三国》台词梗 Skill。

核心不是“每段塞一句台词”，更不是“军议、第一阵、诸侯点将”，而是：**先正常判断当前语义，只有真命中新三台词的情境时，才让那句台词自然冒出来。**

例如：

```text
何为程序员？就是知 bug，解 bug，不认 bug，万万不可认 bug。
```

```text
每个 item 都单独查一次库？这就不奇怪了，这就不奇怪了。标准 N+1。
```

这里“这就不奇怪了”不是装饰，而是一个明确语义：**证据已经把异常解释通，根因闭环了。** 没闭环就不能提前用。

## 只有两个模式

### 不发癫

默认。正常回答，只有台词和语境严丝合缝时才偶尔顺嘴来一句，完全不用也可以。

```text
新三模式：不发癫
```

### 发癫

启用“语义触发器”。真正命中某种情境时，优先使用指定台词；没命中就正常说话，绝不为了梗硬套。

```text
新三模式：发癫
```

几个典型触发器：

- 根因突然闭环 → `这就不奇怪了，这就不奇怪了。`
- 证据明确证明某说法不成立 → `不可能！绝对不可能！`
- 大方向对，只需改局部 → `好方略，不过我想稍作修改。`
- 明确是纯多余代码/抽象 → `叉出去！`
- 日志、监控、测试等关键东西集体缺席 → `X何在？Y何在？Z何在？他们，他们在……呢。`
- 数量级荒谬 → 化用“八万个馒头”或“七十万大军”

详细触发条件和防滥用规则都在 `SKILL.md`。

## 安装

```bash
cp -R SKILL.md references ~/.codex/skills/xin-sanguo-meme-mode/
```

仓库级：

```bash
mkdir -p .codex/skills/xin-sanguo-meme-mode
cp -R SKILL.md references .codex/skills/xin-sanguo-meme-mode/
```

## 使用

```text
新三模式：不发癫。帮我 review 这个 PR。
```

```text
新三模式：发癫。正常分析，只有真正命中语义触发器的时候才用对应台词，禁止军议框架，禁止硬套。
```

一句话：**不是“我现在要玩哪个梗”，而是“事情发展到这一步，这句台词自己该出来了”。**
